# University Projects Repository

Этот репозиторий содержит коллекцию учебных и курсовых проектов, выполненных в рамках обучения в университете.

## Структура репозитория

- **[SAST_Scanner_WebSec](./SAST_Scanner_WebSec/)**: Учебный проект по теме «Безопасность веб-сервисов». Содержит исходный код локального статического анализатора кода (SAST) на платформе .NET (C#).
- **[Telegram_Dating_Bot](./Telegram_Dating_Bot/)**: Телеграм-бот для знакомств студентов. Написан на Python (python-telegram-bot, SQLite). Включает систему онбординга, поиск анкет, лайки и панель модерации.
