# MIREA Projects Repository

Этот репозиторий содержит коллекцию учебных и курсовых проектов, выполненных в рамках обучения в РТУ МИРЭА.

## Структура репозитория

- **[SAST_Scanner_WebSec](./SAST_Scanner_WebSec/)**: Проект (Ознакомительная практика) по теме «Безопасность веб-сервисов». Содержит исходный код локального статического анализатора кода (SAST) на платформе .NET (C#) и всю сопровождающую документацию (отчёты, пояснительные записки).
- **[Telegram_Dating_Bot_MIREA](./Telegram_Dating_Bot_MIREA/)**: Телеграм-бот для знакомств студентов РТУ МИРЭА. Написан на Python (python-telegram-bot, SQLite). Включает систему онбординга, поиск анкет, лайки и панель модерации.
