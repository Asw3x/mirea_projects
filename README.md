# Study Projects Repository

Этот репозиторий содержит коллекцию учебных пет-проектов и практических работ.

## Структура репозитория

- **[SAST_Scanner_WebSec](./SAST_Scanner_WebSec/)**: Учебный проект по информационной безопасности. Содержит исходный код локального статического анализатора кода (SAST) на платформе .NET (C#).
- **[Telegram_Dating_Bot](./Telegram_Dating_Bot/)**: Телеграм-бот для знакомств. Написан на Python (python-telegram-bot, SQLite). Включает систему онбординга, поиск анкет, лайки и панель модерации.
