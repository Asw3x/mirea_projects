# mirea_projects

Репозиторий для выполнения задач по программированию в РТУ Мирэа.

## Структура репозитория

```
mirea_projects/
├── lab1/   # Лабораторная работа 1
├── lab2/   # Лабораторная работа 2
├── lab3/   # Лабораторная работа 3
└── ...
```

Каждая папка `labN` содержит:
- `task.md` — условие задачи
- `solution.py` — решение на Python

## Как использовать

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Asw3x/mirea_projects.git
   ```
2. Перейти в нужную папку лабораторной работы:
   ```bash
   cd lab1
   ```
3. Запустить решение:
   ```bash
   python solution.py
   ```

## Требования

- Python 3.x
