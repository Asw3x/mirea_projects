# Статический анализатор кода (SAST)

Данный проект разработан в рамках учебной практики по теме **«Безопасность веб-сервисов»**. Представляет собой приложение для локального статического анализа исходного кода на выявление потенциальных веб-уязвимостей (SQL-инъекции, утечки секретов, выполнение команд ОС и использование слабой криптографии).

## 📁 Структура проекта

- `docs/` — пояснительная записка, отчёты по практике и титульные листы.
- `src/` — исходный код приложения (Windows Forms / C#). 

## ⚙️ Особенности реализации

- **Разделение логики**: Графический интерфейс отделен от ядра сканирования (`SecurityLib`), что позволяет легко портировать логику.
- **Комбинированный анализ**: Использование сигнатурного (через Regex) и эвристического подходов для минимизации ложных срабатываний.
- **Глубокий анализ (Deep Scan)**: Опциональный режим для выявления использования слабой криптографии (например, MD5 или SHA1).
- **Расширяемая база сигнатур**: Возможность загрузки кастомных правил (ScannerRule) из внешних XML-файлов без перекомпиляции программы.

## 🚀 Запуск и использование

1. Откройте решение `WindowsFormsApp1.sln` из директории `src/` в Visual Studio.
2. Соберите и запустите проект.
3. В графическом интерфейсе введите или вставьте исходный код для проверки.
4. Нажмите `Analyze` для получения таблицы с детальной сводкой найденных уязвимостей, их уровнем риска (Severity) и номерами строк.
