# Telegram Dating Bot

Учебный проект Telegram-бота для знакомств (аналог Tinder).

## 🚀 Особенности
- **Онбординг**: Регистрация с последовательным сбором данных: Имя, Возраст, Пол, Кого ищу, Город, Био, Фотографии.
- **Анкеты и лайки**: Просмотр анкет других пользователей, возможность ставить лайки и получать уведомления о взаимной симпатии.
- **Админка**: Встроенная система модерации для администраторов (баны, уведомления).
- **База данных**: Использование SQLite через кастомный модуль `db.py` с поддержкой пула соединений.
- **Поддержка медиа**: Отправка видео при бане и обработка нескольких фотографий в профиле.

## 📁 Структура
- `bot_end.py` — главный файл бота (обработка команд, состояний, логика общения).
- `db.py` — модуль для работы с базой данных SQLite.
- `requirements.txt` — зависимости проекта (python-telegram-bot и др.).
- `ban_message.mp4` / `waiting_banner.jpg` — медиафайлы, используемые ботом.

## 🛠️ Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Задайте переменную окружения `TOKEN` с токеном вашего Telegram-бота.
3. Запустите бота: `python bot_end.py`
